# Datasets

Canonical wide-format LTSF benchmark CSVs (first column `date`, then one column
per channel), byte-identical to the Autoformer release files used throughout
the long-term-forecasting literature. Source mirror (public, no auth):
HuggingFace `AutonLab/Timeseries-PILE`, path `forecasting/autoformer/`.

## How to (re)download

```powershell
.venv\Scripts\python.exe scripts\download_data.py                  # core
.venv\Scripts\python.exe scripts\download_data.py --with-ecl       # + electricity
.venv\Scripts\python.exe scripts\download_data.py --nonstationary  # + exchange_rate, national_illness
.venv\Scripts\python.exe scripts\download_data.py --traffic        # + traffic (862 ch, ~130 MB)
```

The script is idempotent (files already present are skipped) and rewrites
`checksums.txt` (SHA-256 of every CSV in this folder) after each run.
